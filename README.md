# 🚗 Alcohol-Based Ignition Lock System Using NodeMCU

## 📌 Project Overview

The Alcohol-Based Ignition Lock System is a smart safety solution designed to prevent drunk driving. This system uses an MQ-3 alcohol sensor and NodeMCU microcontroller to detect alcohol levels in the driver’s breath and automatically control the vehicle ignition system.

---

## 🎯 Objectives

* Prevent vehicle ignition when alcohol is detected
* Reduce road accidents caused by drunk driving
* Provide real-time alerts using LCD and buzzer
* Develop a low-cost and reliable safety system

---

## ⚙️ Components Used

* NodeMCU (ESP8266)
* MQ-3 Alcohol Sensor
* 16x2 LCD Display
* Buzzer
* DC Motor
* Jumper Wires & Power Supply

---

## 🔧 Working Principle

1. The MQ-3 sensor detects alcohol from the driver's breath
2. NodeMCU processes sensor data
3. If alcohol level exceeds threshold:

   * Ignition is turned OFF
   * Buzzer alert is activated
   * Warning displayed on LCD
4. If alcohol level is safe:

   * Ignition remains ON
   * System operates normally
